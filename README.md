## GitHub Changelog 対訳リーダー (Canvas 拡張機能)

GitHub Changelog の最新記事を英語原文と日本語訳で左右並列に対訳表示し、快適に読み進めることができる Copilot Canvas 拡張機能です。

### 概要
- **左右対訳表示**: 英語原文と日本語訳を段落（ブロック）ごとに並べて表示し、スクロールやフォーカスが連動。
- **キーボードフレンドリー**: Vim風・WASD風のキーバインドを含む多彩なショートカットで、記事や段落をマウスレスで素早く巡回可能。
- **フィルタ・検索**: 年月セレクター、カテゴリ別絞り込み、翻訳ステータス（対訳あり / 原文のみ）、全文検索に対応。
- **非同期バックグラウンド翻訳キュー**: 最新期間の未翻訳記事を裏で1件ずつ順次自動翻訳。
- **手動翻訳の最優先割り込み**: 読みたい記事で翻訳ボタン（または `T` キー）を押すと、通常キューの先頭に割り込んで最優先で即時処理。

### 大まかな仕組み

```
┌────────────────────────────────────────────────────────┐
│  GitHub Changelog RSS (https://github.blog/...)        │
└──────────────────────────┬─────────────────────────────┘
                           │ 記事フェッチ・ブロック分割
                           ▼
┌────────────────────────────────────────────────────────┐
│  ローカルキャッシュ (data/changelog-all.json)           │
│  ※著作権配慮のためリポジトリ除外 (.gitignore)         │
└────────────────────┬───────────────────────────────────┘
                     │ REST API (ループバック/CSRF保護)
                     ▼
┌────────────────────────────────────────────────────────┐
│  Canvas UI (GitHub Changelog 対訳リーダー)             │
│  - 左右対称の段落アライメント / サニタイズ表示         │
│  - キュー進捗プログレスバー / 一括翻訳ボタン           │
└────────────┬─────────────────────────────▲─────────────┘
             │ 優先度付き翻訳リクエスト    │ リアルタイム反映
             ▼                             │
┌──────────────────────────────────────────┴─────────────┐
│  Copilot App セッション連携 (Priority Queue)           │
│  - 【高優先度】手動リクエスト（即座に先頭割り込み）    │
│  - 【通常優先度】最新未翻訳記事（1件ずつ順次処理）     │
│  - チャットセッション上で翻訳状況・品質を目視確認      │
└────────────────────────────────────────────────────────┘
```

1. **記事の取得とローカル管理**:
   - 公式 RSS フィードから記事を取得し、HTML を段落・見出し単位（ブロック）に分解してローカルに保持します。
   - 初回起動時に未取得の場合は自動フェッチが走るほか、`node scripts/fetch-changelog.mjs` でも手動更新できます。
   - ※著作権や利用規約に配慮し、取得した記事データは `.gitignore` によりリポジトリにはコミットされません。
2. **Canvas サーバーとセキュリティ**:
   - `@github/copilot-sdk/extension` を利用してローカルのループバックアドレス（`127.0.0.1`）でサーバーを起動します。
   - ループバック Host/Origin 検証、インスタンス固有の `X-CSRF-Token`、再帰的 DOM サニタイザーを備え、安全に動作します。
3. **Copilot App セッション駆動の優先度キュー**:
   - 処理の進捗がユーザーに見えるよう、現在開いている Copilot App のチャットセッション（`copilotSession.send()`）に対してタスクを1件ずつ順次送信します。
   - サイドバーの「⚡ 未翻訳を一括翻訳 (非同期)」を押すと、表示中の未翻訳記事が通常キュー（`normal`）に追加されます。
   - キュー処理中にユーザーが別の記事で「日本語訳を生成」を押す（または `T` キーを押す）と、**優先度「高（`high`）」としてキューの先頭に割り込み**、現在実行中の記事が終わり次第、最優先で翻訳されます。
   - 翻訳完了ごとに画面の対訳・サイドバーバッジ・進捗バーがリアルタイムに自動更新されます。

### 使い方

#### 1. Canvas の起動
Copilot App の Canvas 一覧から「GitHub Changelog 対訳リーダー」を開きます。

#### 2. 記事のブラウズと絞り込み
- **年月セレクター**: 最新（直近の更新サイクル）、全期間、または各年月（例: 2026年9月）を選択して記事を切り替えられます。
- **カテゴリ / ステータス**: Copilot、Actions、Security などのカテゴリ別や、翻訳済み（対訳あり）/ 未翻訳（原文）で絞り込みが可能です。
- **検索**: タイトルおよび本文（英語・日本語）をインクリメンタル検索できます。

#### 3. バックグラウンド一括翻訳と割り込み
- サイドバーの **「⚡ 未翻訳を一括翻訳 (非同期)」** をクリックすると、現在選択中の期間の未翻訳記事がバックグラウンドキューに登録され、順次翻訳されます。
- ボタン下の **「順序」** で「新しい順」/「古い順」を選べます（選択はブラウザに保存されます）。
- **「Auto (efficiency)」** にチェックが入っていると（既定 ON）、翻訳送信前に Copilot App セッションのモデルを `auto`（efficiency）に切り替えます。SDK にメッセージ単位のモデル指定がないため、**セッション全体のモデル設定が変更される**点に注意してください。
- 進捗状況（完了件数 / 残り件数 / 進捗バー）がサイドバーに表示され、一時停止（`⏸️`）や中止（`⏹️`）も可能です。
- キュー処理中であっても、今すぐ読みたい記事を開いて **「日本語訳を生成」**（または `T` キー）を押せば、キュー先頭に割り込んで最優先で処理されます。

#### 3. 主なキーボードショートカット
ヘッダー右上の「?」アイコンをクリックするか、以下のキーで素早く操作できます。

| 操作 | キー |
|---|---|
| **次の記事 / 前の記事** | `→` / `L` / `D`（次へ）、`←` / `H` / `A`（前へ） |
| **次の段落 / 前の段落** | `↓` / `K` / `S`（次へ）、`↑` / `J` / `W`（前へ・ループ対応） |
| **日本語訳の生成** | `T` |
| **検索にフォーカス** | `Ctrl + K` または `Cmd + K` |
| **ダーク / ライトモード切替** | `M` |
| **サイドバー開閉** | `B` |
| **ショートカットヘルプ表示** | `?` または `/` |
| **選択解除 / ポップアップを閉じる** | `Escape` |

#### 4. 翻訳の手順
1. リストから「原文」と表示されている未翻訳の記事を選択します。
2. ヘッダーの「日本語訳を生成」ボタンを押すか、キーボードの `T` を押します。
3. Copilot App のチャットセッションに翻訳リクエストが自動投入され、翻訳が開始されます。
4. 翻訳が完了すると、Canvas 画面の日本語対訳エリアおよびサイドバーの一覧バッジ（「対訳あり」）が自動的に更新されます。
