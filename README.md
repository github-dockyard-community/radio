# GitHub dockyard Radio

配信で利用したコンテンツなどを公開します。

---

## GitHub Changelog Digest (GitHub Actions)

`.github/workflows/github-changelog-digest.md` が RSS を取得し、対象期間のダイジェストを Discussions に作成・更新します。

- RSS は `curl` で取得します。Copilot CLI のオフラインモードではネイティブの `web-fetch` は利用できません。
- CLI の `engine.args` による `--allow-url github.blog` と、ファイアウォールの `network.allowed` による `github.blog` の許可は両方必要です。どちらも許可対象をこのホストに限定しています。
- 取得・解析に失敗した場合は `missing_tool` / `missing_data` safe-output で詳細を報告し、Discussion は新規作成・更新しません。既存の記事一覧とリアクションを保持します。Actions の成功表示だけでなく、実行サマリーのエラー報告も確認してください。

ワークフローを変更した際は、gh-aw CLI を更新してから lock ファイルを再生成し、ソースと一緒にコミットします。このワークフローの生成には **gh-aw v0.92.0** を使用しています。

```sh
gh extension upgrade githubnext/gh-aw
gh aw compile github-changelog-digest
```

## GitHub Changelog 対訳リーダー (Canvas 拡張機能)

GitHub Changelog の最新記事を英語原文と日本語訳で左右並列に対訳表示し、快適に読み進めることができる Copilot Canvas 拡張機能です。

### 概要
- **左右対訳表示**: 英語原文と日本語訳を段落（ブロック）ごとに並べて表示し、スクロールやフォーカスが連動。
- **キーボードフレンドリー**: Vim風・WASD風のキーバインドを含む多彩なショートカットで、記事や段落をマウスレスで素早く巡回可能。
- **フィルタ・検索**: 年月セレクター、カテゴリ別絞り込み、翻訳ステータス（対訳あり / 原文のみ）、全文検索に対応。
- **非同期バックグラウンド翻訳キュー**: 最新期間の未翻訳記事を裏で1件ずつ順次自動翻訳。
- **手動翻訳の最優先割り込み**: 読みたい記事で翻訳ボタン（または `T` キー）を押すと、通常キューの先頭に割り込んで最優先で即時処理。

### 大まかな仕組み

```
┌────────────────────────────────────────────────────────┐
│  GitHub Changelog RSS (https://github.blog/...)        │
└──────────────────────────┬─────────────────────────────┘
                           │ 記事フェッチ・ブロック分割
                           ▼
┌────────────────────────────────────────────────────────┐
│  ユーザー管理ディレクトリの月別 JSON                    │
│  YYYY-MM.json + 再構築できる見出し索引                  │
└────────────────────┬───────────────────────────────────┘
                     │ REST API (ループバック/CSRF保護)
                     ▼
┌────────────────────────────────────────────────────────┐
│  Canvas UI (GitHub Changelog 対訳リーダー)             │
│  - 左右対称の段落アライメント / サニタイズ表示         │
│  - キュー進捗プログレスバー / 一括翻訳ボタン           │
└────────────┬─────────────────────────────▲─────────────┘
             │ 優先度付き翻訳リクエスト    │ リアルタイム反映
             ▼                             │
┌──────────────────────────────────────────┴─────────────┐
│  Copilot App セッション連携 (Priority Queue)           │
│  - 【高優先度】手動リクエスト（即座に先頭割り込み）    │
│  - 【通常優先度】最新未翻訳記事（1件ずつ順次処理）     │
│  - チャットセッション上で翻訳状況・品質を目視確認      │
└────────────────────────────────────────────────────────┘
```

1. **記事の取得とローカル管理**:
   - 公式 RSS フィードから記事を取得し、HTML を段落・見出し単位（ブロック）に分解して、指定ディレクトリの `YYYY-MM.json` に保持します。記事の `date` が所属月を決めます。既定の保存先はリポジトリの `data` ディレクトリです。
   - 保存先設定は `$COPILOT_HOME/extensions/changelog-reader/artifacts/settings.json`（未設定時は `~/.copilot/...`）に保存されるため、セッションや worktree を作り直しても同じ設定を使えます。
   - 読み込みだけでは RSS を取得しません。データがない場合は0件の一覧を表示します。「最新記事一覧を更新」で明示的に RSS を取得できます。更新時は既存記事を残し、原文が変わっていない部分の翻訳を引き継ぎます。
   - 指定ディレクトリの作成、Git / OneDrive 等による管理、バックアップ、複数端末間の同期はユーザーが行います。アプリは選択された JSON の読み書きと整合性の確認を担当し、独自の同期機能は持ちません。
2. **Canvas サーバーとセキュリティ**:
   - `@github/copilot-sdk/extension` を利用してローカルのループバックアドレス（`127.0.0.1`）でサーバーを起動します。
   - ループバック Host/Origin 検証、インスタンス固有の `X-CSRF-Token`、再帰的 DOM サニタイザーを備え、安全に動作します。
3. **Copilot App セッション駆動の優先度キュー**:
   - 処理の進捗がユーザーに見えるよう、現在開いている Copilot App のチャットセッション（`copilotSession.send()`）に対してタスクを1件ずつ順次送信します。
   - サイドバーの「⚡ 未翻訳を一括翻訳 (非同期)」を押すと、選択期間全体の未翻訳記事が通常キュー（`normal`）に追加されます。読み込み済みページや検索結果だけではありません。サーバーが確定した対象件数・順序を確認してから登録します。
   - キュー処理中にユーザーが別の記事で「日本語訳を生成」を押す（または `T` キーを押す）と、**優先度「高（`high`）」としてキューの先頭に割り込み**、現在実行中の記事が終わり次第、最優先で翻訳されます。
   - 翻訳完了ごとに画面の対訳・サイドバーバッジ・進捗バーがリアルタイムに自動更新されます。

### 使い方

#### 1. Canvas の起動
Copilot App の Canvas 一覧から「GitHub Changelog 対訳リーダー」を開きます。

#### 2. 対訳データの保存先
- サイドバーの「対訳データの保存先」に、利用する既存ディレクトリの絶対パスを入力し、「保存先を比較」を押します。ディレクトリはアプリが作成しないため、事前に用意してください。互換用初期値のリポジトリ内 `data` は worktree のアーカイブ等で失われ得るため、長期利用するデータはユーザー管理ディレクトリへ切り替えてください。
- データは `2026-09.json` のような月別ファイルで、各ファイルにその月の記事・英語本文・日本語訳を保存します。別 worktree やセッションでも同じディレクトリを設定すれば、同じ対訳データを利用できます。
- 比較画面に、現在使用中と変更先それぞれの実パス、形式、月数、総記事数、翻訳済み件数、最古～最新の記事日付を表示します。日付範囲は保持期限ではありません。比較は全月を順に検証し、進捗表示・中止が可能です。
- 比較後に **「変更先のデータを使う」「現在のデータを変更先へコピー」「今は変更しない」** から選びます。自動コピー・自動統合はしません。コピーは**全月の置換**です。変更先だけにある月・記事・訳は削除されます。無関係なファイルと旧保存先は変更しません。空の変更先を使用したときは0件表示となり、ファイルも RSS 取得も自動作成・実行しません。
- 翻訳中、待機キューあり（一時停止中を含む）、RSS更新中は切替・再読み込みできません。比較後にデータや設定が変わった場合は、実行を拒否して比較のやり直しを求めます。切替成功時は一覧・選択記事・本文を直ちに置き換えます。翻訳要求には保存先の世代・原文指紋・一意なリクエストIDを付け、中止・タイムアウト後の遅延結果を拒否します。
- 外部の Git / OneDrive 等がファイルを更新した場合、古いデータでの保存は拒否します。処理を中止・完了させた後に **「保存先から再読み込み」** で取り込んでください。別セッションの設定保存は実行中の接続先を暗黙には変更しません。設定版が競合した場合はセッションを再起動して確認してください。
- Git、OneDrive 等での管理・同期・バックアップはユーザーの責務です。同期する場合は、選択したディレクトリ自体を希望する方法で管理してください。アプリから GitHub 等への直接同期は行いません。

同一PCの協調する拡張機能・CLI間は、所有情報付きの `.lock` ファイルで書き込みを排他し、内容のハッシュで外部更新を検知します。ロックはネットワーク待ちや比較画面の表示中には保持しません。異常終了でロックが残った場合は、他のアプリ・CLIが使用していないことを確認してから、エラーに示すロックファイルだけを手動で削除してください。他者のロックをアプリが自動削除することはありません。OneDrive等による複数端末間の分散排他や、非協調の外部アプリによる最終検証～置換間の競合までは保証しません。CLIも共通の検証・排他を使い、取得中の外部更新は取り込まず停止します。

月をまたぐ更新・移行・全置換では、`.changelog-transactions` に操作記録と変更前後のデータを先に保存します。中断後は通常の閲覧・保存を止め、**「未完了操作の残りを適用」「未完了操作を元に戻す」** で明示的に復旧します。記録された変更前／変更後以外の内容に外部編集されていたり、復旧用データが欠損していたりする場合は上書きせず停止します。復旧完了後は操作用データを削除します。通常の単月更新はその月だけを原子的に置換します。

データと設定は別ファイルのため、保存先切替全体は単一の原子操作ではありません。切替開始前に共通設定領域の `settings.json.switch.json` に意図を記録し、変更先の処理完了後に設定を書きます。設定保存だけが失敗した場合は「変更先データの処理は完了・切替は未完了」と通知し、旧接続を維持します。自動ロールバック・再上書きはしません。変更先の未完了データ操作があれば先に復旧し、元・変更先・設定を確認して切替記録を解除した後、`/restart-session` してください。応答喪失時は状態を確認し、上書きを再送しないでください。これらの操作記録は常用バックアップではありません。

0バイト、不正JSON、月をまたぐ記事ID重複、ブロックID重複、ファイル名と記事日付の不一致、同期競合らしい月別ファイル名は、空データとして扱わず確認を促します。旧 `localPath` が標準名なら親ディレクトリとして読み替えます。任意名なら黙って別ファイルを選ばず、設定修正を案内します。旧リポジトリ同期設定は使用しません。

#### 月別形式への移行とファイル管理

旧 `changelog-all.json`（または旧 `changelog-2026-09.json`）は自動分割しません。Canvasの **「月別形式へ移行」** で検証結果の件数・月数を確認し、明示的に実行してください。記事と訳を保ったまま月別へ分割し、元ファイルはバイト単位で同じ内容を `.changelog-legacy` に退避します。重複や不正データは自動修復しません。旧形式と月別形式の混在も拒否します。変更先が旧形式の場合は、比較画面の移行ボタンから先に移行できます。マーカーのない既存月別ファイルは、明示的な「月別形式として使用」で検証・採用します。

```text
data\
  changelog-storage.json          # 形式マーカー（version: 1, format: "monthly"）
  2026-09.json                    # 正本：その月の全記事・本文・訳文
  2026-10.json
  .changelog-cache\index.json     # 再生成可能な索引（本文なし）
  .changelog-transactions\        # 未完了操作がある間の記録・復旧データ
  .changelog-legacy\              # 明示移行した旧全件ファイル
```

Gitではマーカー・月別JSONを管理し、`.changelog-cache/` と `*.lock` は除外できます。移行直後の `.changelog-legacy/` はバックアップ方針に従って保管してください。未完了の `.changelog-transactions/` は復旧まで削除・編集しないでください。正常終了後は操作ごとの記録が消えます。索引は正本ではないため、失われても再構築できます。

CLIも同じ月別形式・検証・排他を利用します。保存先は明示指定でき、Canvasのグローバル設定は読み書きしません。旧形式は先にCanvasで移行してください。

```powershell
node scripts\fetch-changelog.mjs --data-directory "C:\path\to\translation-data"
```

拡張機能を更新したらプロバイダーの再起動が必要です。`extensions_reload` が利用できない環境では `/restart-session` を実行し、Canvasを開き直してください。Canvasを開き直すだけではバックエンドは更新されません。UIはAPIの版と応答形式を検証し、新しい画面と古いバックエンドが混在している場合は操作を停止して再起動を案内します。

#### 3. 記事のブラウズと絞り込み
- **年月セレクター**: 最新（直近の更新サイクル）、全期間、または各年月（例: 2026年9月）を選択して記事を切り替えられます。
- **カテゴリ / ステータス**: Copilot、Actions、Security などのカテゴリ別や、翻訳済み（対訳あり）/ 未翻訳（原文）で絞り込みが可能です。
- **段階的な読み込み**: 一覧は見出し要約を50件ずつ取得し、「次の50件を表示」で追加します。本文は選択記事が属する月だけを読み、サーバーは最大3か月、ブラウザーは最大3記事の本文を保持します。有効な索引がある通常起動・状態確認・全期間の最初のページでは月別本文を読みません。索引の初回作成・再構築時だけは全月を順に検証します。
- **検索**: 検索語を入力し、Enterまたは「検索」を押して実行します。全期間を選べば未閲覧の過去月も含め、サーバーが月別に英語・日本語の本文を順次検索します。途中の一致件数・進捗・中止を表示し、完了後に検索結果をページ表示します。入力のたびに全月を読み直しません。検索中・検索後にデータが変われば結果を無効化し、再検索を求めます。
- **記事一覧の更新**: 「最新記事一覧を更新」を押すとRSSから記事を取得し、一覧に反映します。新着件数が表示されますが、翻訳は開始されません。翻訳したい記事は個別に「日本語訳を生成」するか、表示中の未翻訳記事を「未翻訳を一括翻訳」でキューに追加してください。
- **更新エラー**: 更新APIのHTTPエラーや不正な応答、RSS取得の失敗は理由とともに表示されます。更新APIが見つからない場合は拡張機能を再起動し、Canvasを開き直してください（上記の再起動手順を参照）。RSS取得に失敗した場合は既存キャッシュ・翻訳を変更しません（2ページ目以降のHTTP 404はフィード終端として扱います）。不正な既存キャッシュも上書きせず、確認を促します。

回帰テスト: `node --experimental-vm-modules --test scripts/changelog-refresh.test.mjs scripts/changelog-storage.test.mjs scripts/changelog-monthly.test.mjs`

#### 4. バックグラウンド一括翻訳と割り込み
- サイドバーの **「⚡ 未翻訳を一括翻訳 (非同期)」** をクリックすると、現在選択中の期間の未翻訳記事がバックグラウンドキューに登録され、順次翻訳されます。
- ボタン下の **「順序」** で「新しい順」/「古い順」を選べます（選択はブラウザに保存されます）。
- **「Auto (efficiency)」** にチェックが入っていると（既定 ON）、翻訳送信前に Copilot App セッションのモデルを `auto`（efficiency）に切り替えます。SDK にメッセージ単位のモデル指定がないため、**セッション全体のモデル設定が変更される**点に注意してください。
- 進捗状況（完了件数 / 残り件数 / 進捗バー）がサイドバーに表示され、一時停止（`⏸️`）や中止（`⏹️`）も可能です。
- キュー処理中であっても、今すぐ読みたい記事を開いて **「日本語訳を生成」**（または `T` キー）を押せば、キュー先頭に割り込んで最優先で処理されます。

#### 5. 主なキーボードショートカット
ヘッダー右上の「?」アイコンをクリックするか、以下のキーで素早く操作できます。

| 操作 | キー |
|---|---|
| **次の記事 / 前の記事** | `→` / `L` / `D`（次へ）、`←` / `H` / `A`（前へ） |
| **次の段落 / 前の段落** | `↓` / `K` / `S`（次へ）、`↑` / `J` / `W`（前へ・ループ対応） |
| **日本語訳の生成** | `T` |
| **検索にフォーカス** | `Ctrl + K` または `Cmd + K` |
| **ダーク / ライトモード切替** | `M` |
| **サイドバー開閉** | `B` |
| **ショートカットヘルプ表示** | `?` または `/` |
| **選択解除 / ポップアップを閉じる** | `Escape` |

#### 6. 翻訳の手順
1. リストから「原文」と表示されている未翻訳の記事を選択します。
2. ヘッダーの「日本語訳を生成」ボタンを押すか、キーボードの `T` を押します。
3. Copilot App のチャットセッションに翻訳リクエストが自動投入され、翻訳が開始されます。
4. 翻訳が完了すると、Canvas 画面の日本語対訳エリアおよびサイドバーの一覧バッジ（「対訳あり」）が自動的に更新されます。
